# Grocery Shopping Website

A front-end grocery shopping website built for a web design competition, with a landing page, exclusive-offers banner, gallery and login page.

## Pages

- `home.html`: home page with navigation (home, gallery, contact, about us) and a "Shop Now" offer section
- `login.html`: login page

## Tech stack

HTML5 · CSS3

## Running

No build step is needed. Open `home.html` in a browser.
